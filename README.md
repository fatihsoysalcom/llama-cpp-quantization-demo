# llama.cpp Quantization Demo

This Python script demonstrates the core concept of weight quantization as used in llama.cpp. It simulates quantizing a small weight tensor to 8-bit and 4-bit precision, showing the approximation and potential memory savings.

## Language

`python`

## How to Run

Run this script using Python: `python quantization_demo.py`
